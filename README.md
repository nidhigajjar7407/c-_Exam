      <p>This project is based on oop in c++.It contains different programs that demonstrates important oop concepts such as classes, objects, encapsulations, inheritance, polymorphisms and abstractions and virtual functions . The project starts with basic classes and gradually moves toward advanced concepts like inheritance and runtime polymorphism.</p>

    </hr>
      <ul>
        <li>Movie class</li>
        <li>Bank Account</li>
        <li>Vehicle, Car and Bike</li>
        <li> Vehicle polymorphism</li>
        <li>Shape, circle and rectangle</li>
      </ul>
    </hr>
      <li><h2> How this project is made </h2></li>
    </hr>
      <p>The project is made step by step using the concepts of c++ OOP. First, classes and objects are created to understand the basic structure. Then , private attributes and and public functions are used to protect and access data. After that, inheritance is used to create derived classes from a base class. Finally, virtual and pure virtual functions are used to demonstrate polymorphism and abstraction.</p>
